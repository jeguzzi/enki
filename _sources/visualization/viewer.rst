======
Viewer
======

pyenki supports two interactive GUI: Qt applications and jupyter notebooks. With both, we can manipulate objects:

- select them
- track them (i.e, switch to an object-centric view)
- move them
- trigger touch events (i.e., by clicking with the mouse on the buttons of a Thymio)

pyenki supports also rendering worlds to images and simulations to videos.

.. seealso::
   See the examples :doc:`../examples/visualization`.
